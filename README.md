# Minha Maratona Marvel

Aplicativo pessoal em formato PWA para acompanhar uma maratona completa do universo Marvel até **Vingadores: Doomsday**.

## Recursos

- Cronologia completa por blocos e universos
- Filmes, séries, especiais, curtas e animações
- Classificação: Essencial, Recomendado, Opcional e Complementar
- Progresso salvo automaticamente no aparelho
- Horas assistidas e restantes
- Calendário inteligente até a data-alvo
- Busca e filtros
- Estatísticas
- Backup e restauração do progresso
- Instalação na Tela de Início do iPhone
- Funcionamento offline após o primeiro carregamento

## Publicar com GitHub Pages

1. Abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione `main` e `/ (root)`.
4. Salve e aguarde a publicação.

Endereço esperado:

`https://rogerio-ops97.github.io/-minha-maratona-marvel/`

## Instalar no iPhone

1. Abra o endereço no Safari.
2. Toque em **Compartilhar**.
3. Selecione **Adicionar à Tela de Início**.
4. Toque em **Adicionar**.

> O progresso é armazenado localmente no navegador. Exporte backups regularmente dentro do aplicativo.
